# Ashen Vigil

Pixel-art side-scroller built with Phaser 3. It's a static build: open `index.html` or serve the folder (GitHub Pages works).

## Controls

You can play with the keyboard or an **Xbox controller**. Other pads that use the standard Gamepad mapping work too. Press any button to wake the controller.

| Action | Xbox controller | Keyboard |
|---|---|---|
| Move / navigate menus | Left stick or D-pad (0.2 deadzone) | Arrows |
| Jump / confirm / advance dialogue | A | Z / Space / Enter |
| Dodge roll / back | B | C / Esc |
| Attack | X | X |
| Heavy attack | Y | W |
| Parry / block | LB | A |
| Spells: storm / frost / dome | RB / LT / RT | S / V / D |
| Drink flask | View | Q / F |
| Heal / bless spells | L3 / R3 | G / R |
| Interact (rest, talk, open, pull, read, enter) | A when a prompt shows, or Up | Up / E |
| Pause | Start | Esc / P |

**Context A:** when you stand on the ground next to something usable (bonfire, the Ash Keeper, a chest, a lever, a lore stone, a door/gate/lift/stair), an on-screen prompt shows the button (`A Rest`, `A Talk`, `A Open`; `[E] ...` without a pad) and A uses it instead of jumping. Step away to jump; D-pad Up always interacts and never jumps. Loot is picked up by walking over it.
